# My Mental Game

Plain-language mental-performance training for **Merrill Bluejays Girls Wrestling**: 7 skills, one screen (and one printed page) each. Read it, tap it, try it at practice. Built to go with *WINNING STATE Wrestling* by Steve Knight (independent companion, not affiliated with or endorsed by the author or publisher).

- `index.html`, `app.js`, `data.js`: the static site (no build step)
- `My_Mental_Game_Workbook.pdf`: the 13-page printable packet
- Sign-in: Google or email link. @mapsedu.org emails are trusted; other emails must be invited by a coach. "Use this phone only" keeps everything on the device.
- Data: Firebase project `merrill-girls-wrestling`, collection `mental`. Coaches and invites are shared with the full YOU University site (bvou).
